# Benchmark AI models and version every result

The repository had selected a model and claimed latency and accuracy without a representative evaluation set. We will benchmark candidate models on project-owned or appropriately consented Cambodian-market packaging before choosing the MVP provider, keep the provider replaceable, record every Extraction Run's model/prompt/schema versions, and version rule-based Assessment Runs separately. This supersedes ADR 0004 and rejects “zero hallucination” or “zero false negative” claims that have not been measured.
