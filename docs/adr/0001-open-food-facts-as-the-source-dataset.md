# Use Open Food Facts as the source dataset

Life Goods is a localized presentation layer rather than an independent food catalog or verification system. Product Lookup reads one static, locally hosted Open Food Facts Dataset Snapshot and keeps every Source Record, image, and Source Assessment visibly attributed; missing data remains unknown. Local hosting improves predictable lookup behavior, but it does not transfer ownership, establish accuracy, or permit silent fallback to a live upstream service.
